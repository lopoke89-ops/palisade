## Standing rules
- Edit `dev/src/` only and rebuild with `python3 dev/build.py`. Never hand-edit `index.html`, `sw.js` or `debug.html`.
- Run the focused tests for the change (`dev/test/run_targeted.sh <group>`) and add a test for each new behavior.
- Keep `palisade.*` storage keys, stable element IDs, the PeerJS host model and Supabase reward authority.
- Bump the protocol only when the packet layout or meaning changes.
- Server changes need a migration in `dev/supabase/migrations/`, PGlite or rolled-back tests, and Big U's approval before applying live. After applying, rename the file to the live version.
- **Never change live player balances, lockers or counters without Big U approving the exact list first.**
- Before committing from GitHub Desktop, fetch and pull `main`.
