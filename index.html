SOLO

Five raids, the last one at night. Dell gathers, repairs, restocks and picks you up when you drop. Hug a wall to fire over it; holes are peeks.

MULTIPLAYER

Co-op over the internet, up to six phones. One person hosts and gets a 4-letter room code; everyone else types it in. Dell comes along either way.

Online play needs the hosted copy of the game (the web link, or the icon on your home screen). This preview can't reach the internet, so solo only here.

IF IT WON'T CONNECT

Phones connect straight to each other. Most home Wi-Fi is fine; some cellular networks block it. If a join hangs, put the host (or everyone) on Wi-Fi. Keep the host's screen on. If the host's phone locks, the game ends for everyone.
